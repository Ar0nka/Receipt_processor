# AI Receipt & Invoice Processor

A small Streamlit application that uses Google's Gemini API to extract information from Romanian receipts and invoices. It accepts images and PDFs, shows successfully processed results in a table, and lets you download them as an Excel workbook.

## Features

- Process one or more JPG, JPEG, PNG, or PDF files in one run.
- Extract supplier, CUI/CIF tax number, document date, expense category, net amount, VAT rate, VAT amount, and gross amount.
- Resize images to a maximum of 1500 × 1500 pixels before sending them for processing. PDFs are sent as PDF bytes.
- Check whether extracted net amount plus VAT is within 0.05 of the extracted gross amount.
- Display successful results in the app and download them as `processed_documents.xlsx`.
- Retry Gemini requests that return an error containing `503`, up to four attempts.

## How it works

For each selected file, the app sends the document and an extraction prompt to the Gemini model configured in `app.py` (`gemini-3.6-flash`). It parses the model response as JSON, adds the filename and a mathematical check, then includes successfully processed files in the results table and Excel download. A three-second pause follows each file.

The totals check only tests the extracted values. It does not verify that the model read the document correctly.

## Requirements

- Python installed on your computer. The repository does not specify a minimum Python version.
- A Google Gemini API key with access to the model ID configured in `app.py`.
- An internet connection when processing documents.

The required Python packages are listed in `requirements.txt`: Streamlit, Google Gen AI SDK, Pillow, pandas, and openpyxl.

## Setup and run

### 1. Clone the repository

```bash
git clone https://github.com/Ar0nka/Receipt_processor.git
cd Receipt_processor
```

### 2. Create and activate a virtual environment

Create it with:

```bash
python -m venv .venv
```

On macOS or Linux, activate it with:

```bash
source .venv/bin/activate
```

On Windows PowerShell, activate it with:

```powershell
.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, you can use Command Prompt instead:

```bat
.venv\Scripts\activate.bat
```

### 3. Install dependencies

With the virtual environment active, run:

```bash
python -m pip install -r requirements.txt
```

### 4. Configure the Gemini API key

In the project root, create a folder named `.streamlit`, then create a file named `secrets.toml` inside it. Add your API key:

```toml
GEMINI_API_KEY = "your_google_gemini_api_key"
```

Replace the example value with your own key. Streamlit reads this setting as `st.secrets["GEMINI_API_KEY"]` when you process files.

### 5. Start the app

```bash
streamlit run app.py
```

Open the local URL printed in the terminal (usually `http://localhost:8501`).

## Use the app

1. Select one or more image or PDF files in the uploader.
2. Choose **Process and Generate Excel**.
3. Review the results table and any per-file errors shown in the app.
4. Choose **Download Excel (.xlsx)** to save the successful results.

The app processes files one at a time. Only files that return parseable JSON and pass the rest of the processing steps appear in the table and workbook; an error on one file is shown without preventing the loop from attempting later files.

## Excel output fields

| Column | Meaning |
| --- | --- |
| `filename` | Uploaded filename |
| `furnizor` | Supplier or issuer name |
| `cui` | CUI/CIF tax number, or `N/A` when the model does not find one |
| `data` | Date requested in `YYYY-MM-DD` format |
| `categorie` | Expense category suggested by the model |
| `total_net` | Net amount before VAT |
| `cota_tva` | VAT rate; when multiple rates are present, the prompt asks for the highest |
| `valoare_tva` | VAT amount |
| `total_brut` | Gross amount |
| `validare_matematica` | `✅ OK` if net + VAT is within 0.05 of gross; otherwise `❌ Check required` |

The app includes only columns returned or added by its processing code. If the model omits a field, that column may be absent for that result.

## Accuracy and limitations

- The extracted values and category are generated by AI and can be missing, misread, or wrong. Check them against the original documents before relying on them, especially for accounting or tax work.
- The prompt asks the model to estimate net amount when it is not stated and to use zero for some missing values. These are model instructions, not independent verification.
- A passing mathematical check only means the extracted net and VAT values add up to the extracted gross within 0.05. It does not establish that any value is accurate.
- The app expects a JSON response. A response that cannot be parsed, or another processing/API error, is shown for that file and is not included in the workbook.
- Only errors containing `503` are retried. The code allows up to four attempts, with waits of 3, 6, and 9 seconds between retry attempts.
- The model name is hardcoded in `app.py`; it must be available to your Google AI account. If Google changes access or model availability, the model setting may need to be updated.

## Privacy and API key security

Each document you process is sent to Google's Gemini API. Receipts and invoices may contain personal, financial, or business information. Only upload documents you are authorized to share, and review Google's current API terms and privacy information before sending sensitive documents.

Keep `.streamlit/secrets.toml` private. Never paste your API key into `app.py`, commit it to Git, or share it in screenshots or logs. This repository does not include a `.gitignore` file, so check that your secrets file is excluded from Git before committing or publishing it. If a key is accidentally exposed, revoke it and create a new one.

## Troubleshooting

- **Missing `GEMINI_API_KEY` / Streamlit secret error:** Confirm `.streamlit/secrets.toml` is in the project root, the key is spelled exactly `GEMINI_API_KEY`, and the TOML value is quoted.
- **API or model error:** Check your internet connection, API key, account access, and whether `gemini-3.6-flash` is available to your account.
- **One file reports an error:** Confirm the file is a supported JPG, JPEG, PNG, or PDF. The app displays the processing error; files with errors are omitted from the workbook.
- **Excel export fails:** Reinstall dependencies from `requirements.txt` with the virtual environment active.
- **`streamlit` command is not found:** Activate the virtual environment and install dependencies again, or run `python -m streamlit run app.py`.
